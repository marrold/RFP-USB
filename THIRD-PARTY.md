## Derived from third-party work

### Terminus Font — `src/font8x16.h`

The 8x16 glyph table is generated by [`tools/make_font.py`](tools/make_font.py)
from the `Lat15-TerminusBold16` console font: printable ASCII only, one byte
per row. **Linked into the firmware.**

- Copyright (c) 2010-2014 Dimitar Toshkov Zhekov, with Reserved Font Name
  "Terminus Font"
- SIL Open Font License 1.1 — full text at
  [`licenses/OFL-1.1.txt`](licenses/OFL-1.1.txt)
- Upstream: https://terminus-font.sourceforge.net/

`font8x16.h` is a subset of the original glyph data and is *not* distributed
under the reserved name: it is a font table inside this firmware, not a font
called "Terminus Font". OFL 1.1 §5 is satisfied on that basis.

### BOOTSEL button sampling — `bootsel_pressed()` in `src/main.c`

Reading the BOOT button means floating the flash chip select and sampling it
from SRAM with interrupts off. The register sequence follows Raspberry Pi's
published example for doing that; the RP2040/RP2350 bit-layout split and the
rest of the firmware around it are this project's.

- Copyright (c) 2020 Raspberry Pi (Trading) Ltd.
- BSD-3-Clause — full text at
  [`licenses/BSD-3-Clause-RaspberryPi.txt`](licenses/BSD-3-Clause-RaspberryPi.txt)
- Upstream: `pico-examples/picoboard/button/button.c` and
  `tinyusb/hw/bsp/rp2040/family.c`
